Send a message from the mail system you want to test to a mailbox you can read, then give DomainLens that message as it was received. It checks SPF, DKIM and DMARC on the message itself, the server that sent it, and the content. The message is analysed and not stored.

Where to find the source: in Gmail Show original, then Download original; in Thunderbird Ctrl+U; in Apple Mail View → Message → Raw Source. In Outlook, save the message (File → Save As, or drag it to a folder) as a .msg file: everything is read from it except the DKIM signature over the body, which a .msg file does not keep as it was sent.

Attachments, and any file chosen on its own, are read for what they do when opened: links, macros, JavaScript, forms that send what is typed, programs and files hidden inside. They are read in a separate process without network, never opened or run; only their hashes are looked up elsewhere.
