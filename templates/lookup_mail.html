Send a message from the mail system you want to test to a mailbox you can read, then give DomainLens that message as it was received. It checks SPF, DKIM and DMARC on the message itself, the server that sent it, and the content. The message is analysed and not stored.

Where to find the source: in Gmail Show original, then Download original; in Thunderbird Ctrl+U; in Apple Mail View → Message → Raw Source. Outlook only shows the headers (File → Properties): that is enough for everything except verifying the DKIM signature, which covers the body too.
