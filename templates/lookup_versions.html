Whether your sites run a software version with a known, serious vulnerability, the way a version scan does it: each site's home page is asked for once, like a browser, and the version the server shows is compared with the release that has the fix. Nothing is sent to trigger a flaw.

A version that is not shown cannot be judged from outside: many servers hide it, and Debian, Ubuntu and Red Hat put fixes into their own packages without a new version number. Those sites are listed as "cannot tell"; check them on the server itself. An agent-based scanner such as InsightVM sees the installed package and is the reliable source there.
