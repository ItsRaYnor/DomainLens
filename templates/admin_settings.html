Responsible disclosure key

Generate an OpenPGP keypair for your security contact. DomainLens keeps the public half and publishes it at /.well-known/pgp-key.asc, referenced from your /.well-known/security.txt.

The private key is shown once and never stored. It is returned in the response, not written to the database, and cannot be recovered afterwards — so a copy of this installation never hands anyone the key to the disclosures you receive. Save it to your password manager before you leave this page.

A passphrase is optional here; if you set one on the downloaded key later with gpg --edit-key it protects the file at rest in your own keyring.

To check this or any other domain's published key the way a researcher would, use Tools → Responsible disclosure.
