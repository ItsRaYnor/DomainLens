Add monitors

Add one monitor

A monitor re-runs the checks you choose on a schedule and reports what changed since the last run — mail, web, TLS, DNS, as chosen below. It also watches one DNS record, so a record that changes or disappears is reported too.

Puts the registered domain in this unit, so it is also watched for quarantine and expiry, and every monitor of its hosts counts there.

Checks on each run

Compared on every run: a changed value or a name that no longer exists (NXDOMAIN) raises an event — the signal for a dangling record. A for a website, MX for mail, CNAME for a host that points elsewhere.

Import DNS records (zone file or OVHcloud)

Paste a zone file (or connect your OVHcloud DNS account) to automatically create one monitor per matching DNS record — instead of adding hostnames one by one. Uses the same scan frequency as "Add monitor" above.
