## Links checked on their own, and a shorter tools menu

### Links checked on their own

A suspicious link often arrives without the message around it: forwarded, in a chat, read off
a screenshot. Tools → Mail & web (formerly Mail analysis) has a **Links** tab: paste up to ten
links, defanged ones (`hxxp://`, `example[.]com`) and bare host names too. `/tools/mail#links`
opens it.

A link is never opened -- one request can tell a phisher the link was seen, or spend a one-time
token. Each link is judged by:

- what it is: a destination hidden behind an `@`, look-alike letters (shown as read and in
  punycode), a bare or private IP address (also written as one number), a shortener, another
  domain's name in front of the real one, a `javascript:` or `data:` link, plain http;
- whether it imitates your own domains;
- what is known about it: the threat lists, VirusTotal by hash when switched on, when its domain
  was registered (days old is high, not registered is medium), and the blocklists and IP threat
  lists for the address it points to.

The host name is looked up through DNS4EU, so the host's own name server sees a question from
DNS4EU, not from your server. Each link gets a verdict; "nothing found" says it is not proof that
a link is safe.
